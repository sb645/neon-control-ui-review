# NEON 客户控制页

交付物只有 `c.htm`，可本地演示，也可上传到 WLED。

## 本地预览

1. 直接双击 `c.htm`。
2. 页面会自动进入“演示模式”。
3. 点击 Power、8 个预设、亮度、颜色、速度即可看模拟效果。

## 上传到 WLED

1. 先在 WLED 里设置灯带类型、像素数。
2. 建好预设 1-8：纯色、彩虹流动、流星、脉冲、呼吸、音乐律动、派对、夜间。
3. 打开 `http://<灯牌IP>/edit`。
4. 上传 `c.htm` 到 WLED 文件系统。
5. 访问 `http://<灯牌IP>/c.htm`。

## Mock / 真实模式

- 页面加载时会自动探测 `/json/info`。
- 探测成功：显示“已连接”，按钮控制真实灯带。
- 探测失败：显示“演示模式”，只控制页面预览。
- 不需要改代码，不要写死设备 IP。
