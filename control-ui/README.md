# NEON 客户控制页

`c.htm` 是单文件控制页，可本地演示，也可上传到 WLED。

## 本地预览
1. 双击 `c.htm`。
2. 页面会进入“演示模式”。
3. 可测试 Power、8 个效果、单色/双色/主题、速度、强度、反向、保存和定时。

## 上传到 WLED
1. 在 WLED 设置灯带类型和像素数。
2. 建好预设 1-8：纯色、彩虹流动、流星、脉冲、呼吸、音乐律动、派对、夜间。
3. 打开 `http://<灯牌IP>/edit` 上传 `c.htm`。
4. 访问 `http://<灯牌IP>/c.htm`。

## 控制方式
- 页面自动探测 `/json/info`。
- 成功：显示“已连接”，使用相对路径控制真实灯带。
- 失败：显示“演示模式”，只控制页面预览。
- 单色/双色写入 WLED 颜色；主题写入 WLED 调色板。
- 保存当前效果会写入 WLED 预设 9。
